# Educational Knowledge Engine (EKE)

## Vision

EKE is an AI-native educational platform that personalizes learning for every child.

The system should teach concepts instead of memorization and adapt to each learner's pace, interests, mastery, and curriculum.

---

## Core Principles

1. Concept-first architecture
2. Curriculum-aware
3. Student-centric personalization
4. Explain before testing
5. Generate, don't memorize
6. AI assists teachers—not replaces pedagogy
7. Modular architecture
8. Every major feature should be replaceable

---

## Coding Principles

- Small reusable functions
- Strong typing
- Domain-driven design
- Clear documentation
