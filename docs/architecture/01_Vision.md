# Educational Knowledge Engine

Mission:

Build an adaptive educational platform that understands knowledge, not just documents.

The system should transform curriculum into structured educational intelligence that can be reused for personalized teaching, assessment, gamification, and lifelong learning.

Purpose:

This is the why of EKE.

It should describe the product vision, not implementation details.

It should contain
1. The problem

What problem are we solving?

For example:

Educational content exists across textbooks, curriculum books, Olympiad books, worksheets, assignments, exam papers, and answer sheets. These sources overlap in concepts but differ in purpose, difficulty, question style, and assessment expectations.

2. The central vision

The core idea:

Build a persistent educational knowledge system that understands:

Concepts
    ↓
Relationships between concepts
    ↓
Student learning state
    ↓
Question generation
    ↓
Assessment and adaptation
3. The key principle

This should be explicitly documented:

The system should understand the concept independently of any single textbook.

NCERT is not the concept itself.

NCERT
  ↓
helps identify and explain concepts

The concept exists independently:

Canonical Concept
    ↓
Fractions

And multiple sources may refer to it:

NCERT
Olympiad Book
School Worksheet
Exam Paper
4. What EKE should eventually do
Ingest educational material
        ↓
Understand the material
        ↓
Identify concepts
        ↓
Connect concepts
        ↓
Understand question patterns
        ↓
Generate appropriate questions
        ↓
Adapt to the student
5. What this document should NOT contain

Do not put here:

TypeScript interfaces
Database schemas
File paths
Extraction algorithms
Canonicalization rules
Detailed question-generation logic

This document should remain stable even if the implementation changes.
