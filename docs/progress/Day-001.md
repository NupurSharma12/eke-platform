# Goal

Transform the Bolt-generated educational app into a scalable AI-powered learning platform called the Educational Knowledge Engine (EKE).

- Understanding curriculum concepts
- Personalizing learning
- Generating adaptive questions
- Tracking student mastery
- Supporting multiple students

# Major Design Decisions

## Decision 001

The frontend should remain independent from AI.

Instead of calling Claude directly, the UI will communicate with EKE.

```
UI
    ↓
API
    ↓
Educational Knowledge Engine
    ↓
Claude + xysq + RAG
```

---

## Decision 002

The smallest educational unit is **Learning Objective**, not a chapter.

Hierarchy:

```
Subject
    ↓
Chapter
    ↓
Learning Objective
    ↓
Concept
    ↓
Skill
    ↓
Question
```

---

## Decision 003

Knowledge should be extracted once from curriculum material and stored as structured concepts.

Instead of repeatedly retrieving entire PDFs, EKE will:

```
PDF
    ↓
Extract Concepts
    ↓
Store Concepts
    ↓
Generate Questions
```

This reduces token usage and improves consistency.

---

## Decision 004

Questions should test understanding rather than copy textbook wording.

Example:

Instead of asking:

> What are equivalent fractions?

EKE should ask:

> Which of these fractions would represent the same amount if the pizza was cut into more slices?

The engine teaches concepts rather than memorization.

Today's work was mostly architectural.

This architecture should make future development more modular, scalable, and adaptable to different curricula and student learning styles.
